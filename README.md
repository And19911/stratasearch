# Поиск людей под завалом (StrataSearch)

Android-приложение для планшета: подключается по Bluetooth к ящику-приёмнику
(BLE-модуль HC-08, сервис `FFE0`/`FFE1`), показывает метки, которые слышит приёмник,
и ведёт к выбранной метке: примерное расстояние, «ближе/дальше», звуковой сигнал.

Заменяет старое приложение `kz.alphasafety.stratasearch`. Разбор протокола — в [docs/protocol.md](docs/protocol.md).

## Как получить APK

Каждый push собирается в GitHub Actions: вкладка **Actions** → последняя сборка →
раздел **Artifacts** → `StrataSearch-APK-N`. Скачать, распаковать zip, установить APK на планшет
(разрешить установку из неизвестных источников).

## Возможности

- Поиск и подключение к приёмнику, автоподключение к последнему, автопереподключение при обрыве.
- Список всех слышимых меток с уровнем сигнала и расстоянием, свежесть данных.
- Экран поиска метки: крупное расстояние, тренд «ближе/дальше», шкала сигнала, график за минуту,
  писк, учащающийся при приближении. Экран не гаснет.
- Режимы: шахта без завала, шахта с завалом, горная местность (формулы из старого приложения).
- Калибровка по своим точкам (RSSI → метры) для каждого режима, с плавной интерполяцией.
- Журнал всех принятых пакетов в файл + кнопка «Отправить журнал».
- Демо-режим без оборудования (генерирует настоящие пакеты протокола).

## Структура

- `protocol/` — чистый Kotlin: разбор пакетов, сборка кадров из кусков BLE, контрольная сумма,
  формулы расстояния. Покрыт тестами на реальных данных из лога (`./gradlew :protocol:test`).
- `app/` — Android (Kotlin, Jetpack Compose).

Требования: Android 5.0+, Bluetooth LE.
